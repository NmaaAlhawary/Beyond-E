# Beyond-E

Landing page for the **Beyond E. Hackathon**, a 3-day Moodle plugin and feature hackathon for HTU students and faculty (HTU D.Learn Center).

## Editing

Everything that changes lives in the `CONFIG` block near the bottom of `index.html`:

- `applyUrl`: the HTUx application link
- `deadline`: countdown target (Amman time, UTC+3)
- `email`: contact email
- `teamSize`, `prizes` (set `null` to hide the prize card), `logo`
- `timeline`: the 7 dates

Put the poster at `assets/poster.jpg` for the WhatsApp / social share preview, and the logo in `assets/`.
